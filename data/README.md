# Input images

| File | What it is | Size |
|---|---|---|
| `xray_foot.png` | Lateral X-ray of a left foot, blurred by the scanner | 816 × 558 |
| `test_print.png` | A blurred scan of the Northlight Images black-and-white printer test print | 804 × 568 |

Both images were supplied with the original assignment. The original image
files were no longer available, so these copies were **cropped from the
"Original" panels of the figures in the original report**. They have been
resampled once by the plotting library, so they are close to the originals,
not identical to them.

The X-ray carries no patient details.

The test print is the work of Northlight Images. It is included only, in its
blurred form, as test input for sharpening.
